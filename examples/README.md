# Examples

This directory contains small, concrete examples that help contributors and users understand how Atlas resources are structured and applied.

## What belongs here

- Complete sample resources or minimal demonstrations
- Example inputs and expected outputs
- Usage scenarios that clarify how a skill, prompt, workflow, or agent should be applied
- Fixtures used by documentation or smoke tests, when they are intended to be read as examples

## Recommended structure

Use a descriptive directory for a multi-file example, such as `examples/<example-name>/`, or a focused Markdown file for a single example. Include a short README when a directory contains multiple files.

Each example should explain its purpose, prerequisites, how to try it, and what a successful result looks like. Use synthetic data and clearly mark illustrative outputs.

## Existing example

- [Skill example](skill-example/) — a starter example of a resource in the Atlas.

## Suitable contributions

Contribute a small reproducible example for a documented feature, show a realistic but safe use case, or clarify an existing example. Avoid secrets, real personal information, misleading claims, and large copied datasets.
