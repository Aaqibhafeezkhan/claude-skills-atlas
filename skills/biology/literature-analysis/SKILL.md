# Biology Literature Analysis

Extract biological system, experimental design, controls, endpoints, statistical evidence, and limitations. Distinguish correlation from causal evidence and model-system findings from broader claims.

Never invent biological results or citations.

## Purpose

Analyze biology research papers systematically..

## When to use

Use this skill when the task involves biology literature analysis and the user needs a structured, repeatable approach.

## Instructions

Apply the guidance and checks above in sequence. Use the supplied context as the source of truth, make assumptions explicit, and verify important conclusions before presenting them.

## Outputs

- A result tailored to the stated task and audience.
