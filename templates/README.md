# Templates

This directory contains reusable starting points that help contributors create resources with a consistent structure.

## What belongs here

- Skill, prompt, workflow, and agent starter files
- Reusable checklists, report structures, and schemas
- Templates that reduce repetitive setup without prescribing unnecessary content

Templates should guide contributors without being mistaken for finished resources.

## Recommended structure

Use `templates/<template-name>.md` for a single template or `templates/<template-name>/` for a multi-file starter. Explain the intended resource type and how to adapt the placeholders.

A useful template should:

- Make required sections and metadata clear
- Mark replaceable values with descriptive placeholders
- Include concise guidance where contributors may otherwise be unsure
- Avoid embedding credentials, personal details, or project-specific assumptions
- Remain aligned with the current validation rules and contribution guide

## Suitable contributions

Add a template for a resource type that contributors regularly create, improve an existing starter to reflect current conventions, or add a checklist that makes quality and safety easier to assess.
