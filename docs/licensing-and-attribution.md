# Licensing and Attribution

Claude Skills Atlas is distributed under the MIT License. The repository license applies to project materials to the extent that contributors hold the rights to license them. It does not automatically relicense third-party material included in a contribution.

## Before contributing external material

Only submit material that you created or are authorized to redistribute.

Before adapting or including an existing skill, prompt, workflow, agent, example, or other work:

1. Identify the original source and the person or organization that created it.
2. Check the source's license and any additional terms that apply to redistribution, modification, and attribution.
3. Confirm that the license is compatible with including the material in this repository.
4. Preserve required copyright notices, license text, and attribution notices.
5. Add a short attribution note near the adapted material, including the source URL and license when known.
6. Describe substantial changes so readers can distinguish the original work from the adaptation.

Do not assume that publicly accessible content is free to copy, modify, or redistribute. If the source has no clear license, ask the rights holder for permission or contribute an original alternative.

## What to include in a contribution

For original work, identify any significant third-party assets, excerpts, examples, datasets, or dependencies used to create it.

For adapted work, include an attribution section or adjacent note with:

- Original title or resource name.
- Author or copyright holder, when known.
- Canonical source URL.
- License name and link, when available.
- A brief description of the changes made.

Keep attribution factual. Do not imply endorsement by the original author or project.

## Code, examples, and dependencies

Check licenses for code snippets, sample projects, datasets, diagrams, images, and other included assets individually. Follow the relevant license conditions, including notices and source-distribution requirements.

Prefer small, necessary excerpts over copying an entire external resource. Never include credentials, private information, or material that you do not have permission to publish.

## Questions and uncertainty

If ownership, license compatibility, or attribution requirements are unclear, do not include the material until the issue has been resolved with the rights holder or maintainers.
